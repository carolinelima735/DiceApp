# 🎲 DiceApp

Aplicativo desenvolvido para a disciplina de **Programação de Aplicativos**, utilizando **React Native** e **Expo**.

O DiceApp é uma aplicação simples para trabalhar conceitos de desenvolvimento mobile, navegação entre telas e componentes utilizando o ecossistema Expo.

## 🚀 Tecnologias

* React Native
* Expo
* Expo Router
* TypeScript
* JavaScript
* React Native Web

## 📱 Funcionalidades

* 🎲 Aplicação relacionada ao lançamento de dados
* 🏠 Tela inicial
* 🔎 Tela Explore
* 🧭 Navegação por abas
* 🌐 Suporte para execução na Web

## ⚙️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/carolinelima735/DiceApp.git
```

### 2. Acesse a pasta

```bash
cd DiceApp
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npx expo start
```

Para limpar o cache:

```bash
npx expo start -c
```

Após iniciar o Expo, é possível executar o aplicativo utilizando um dispositivo físico, emulador ou navegador, de acordo com a configuração disponível.
